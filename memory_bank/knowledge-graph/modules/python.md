# python

## Purpose

The `python/` directory is the `delta-spark` Python package: thin Python bindings over the Delta Spark API that expose a `DeltaTable` class, builder pattern helpers, testing utilities, and exception classes. It operates in two distinct modes — **classic PySpark** (Py4J JVM bridge) and **Spark Connect** (proto/gRPC serialization) — selected transparently at runtime.

## Two Operating Modes

The single top-level `delta.tables.DeltaTable` class auto-dispatches to one of two implementations based on whether the active `SparkSession` is a remote Connect session:

```python
# python/delta/tables.py:335-339
assert sparkSession is not None
if is_remote():
    from pyspark.sql.connect.session import SparkSession as RemoteSparkSession
    if isinstance(sparkSession, RemoteSparkSession):
        from delta.connect.tables import DeltaTable as RemoteDeltaTable
        return RemoteDeltaTable.forPath(sparkSession, path, hadoopConf)
```

This pattern is repeated in every factory method (`forPath`, `forName`, `create`, `createIfNotExists`, `replace`, `createOrReplace`, `convertToDelta`, `isDeltaTable`). The user never needs to import a mode-specific class — the dispatch is transparent.

## Classic PySpark API (`delta/tables.py`)

### DeltaTable (classic)

`DeltaTable` wraps a JVM-side `io.delta.tables.DeltaTable` object (held as `self._jdt`) obtained via PySpark's Py4J bridge (`sparkSession._sc._jvm`). All method calls delegate to the corresponding JVM method.

#### Public Interface

| Method | Signature | Description |
|--------|-----------|-------------|
| `forPath` | `(sparkSession, path, hadoopConf={})` → `DeltaTable` | Factory: load by path. Passes `hadoopConf` (only `fs.*` / `dfs.*` keys honored on JVM side) |
| `forName` | `(sparkSession, tableOrViewName)` → `DeltaTable` | Factory: load by catalog name or `delta.\`path\`` |
| `isDeltaTable` | `(sparkSession, identifier)` → `bool` | Check if identifier is a Delta table |
| `convertToDelta` | `(sparkSession, identifier, partitionSchema=None)` → `DeltaTable` | Convert Parquet table in-place |
| `create` | `(sparkSession=None)` → `DeltaTableBuilder` | Begin CREATE TABLE DDL builder |
| `createIfNotExists` | `(sparkSession=None)` → `DeltaTableBuilder` | CREATE TABLE IF NOT EXISTS |
| `replace` | `(sparkSession=None)` → `DeltaTableBuilder` | REPLACE TABLE (error if not exists) |
| `createOrReplace` | `(sparkSession=None)` → `DeltaTableBuilder` | CREATE OR REPLACE TABLE |
| `toDF` | `()` → `DataFrame` | Get DataFrame view of the table |
| `alias` | `(aliasName)` → `DeltaTable` | Apply alias (for MERGE) |
| `delete` | `(condition=None)` → `None` | Delete rows matching condition |
| `update` | `(condition=None, set={})` → `None` | Update rows matching condition |
| `merge` | `(source, condition)` → `DeltaMergeBuilder` | Begin MERGE builder |
| `vacuum` | `(retentionHours=None)` → `DataFrame` | Remove unreferenced files |
| `history` | `(limit=None)` → `DataFrame` | Return commit history |
| `detail` | `()` → `DataFrame` | Return table detail info |
| `generate` | `(mode)` → `None` | Generate manifest files (e.g., `"symlink_format_manifest"`) |
| `optimize` | `()` → `DeltaOptimizeBuilder` | Begin OPTIMIZE builder |
| `restoreToVersion` | `(version)` → `DataFrame` | Restore table to a version |
| `restoreToTimestamp` | `(timestamp)` → `DataFrame` | Restore table to a timestamp |
| `upgradeTableProtocol` | `(readerVersion, writerVersion)` → `None` | Protocol version upgrade |
| `addFeatureSupport` | `(featureName)` → `None` | Add table feature (table features protocol) |
| `dropFeatureSupport` | `(featureName, truncateHistory=None)` → `None` | Drop table feature |
| `clone` | `(target, isShallow=False, replace=False, properties=None)` → `DeltaTable` | Clone table |
| `cloneAtVersion` | `(version, target, ...)` → `DeltaTable` | Clone at a specific version |
| `cloneAtTimestamp` | `(timestamp, target, ...)` → `DeltaTable` | Clone at a specific timestamp |

#### JVM Bridge Mechanics

Two key internal helpers convert Python types to JVM types before dispatching to `self._jdt`:

```python
# python/delta/tables.py:867-900
@staticmethod
def _dict_to_jmap(sparkSession, pydict, argname):
    """Convert dict<str, Column|str> to Java HashMap<str, Column>"""
    jvm = sparkSession._sc._jvm
    jmap = jvm.java.util.HashMap()
    for col, expr in pydict.items():
        if isinstance(expr, Column) and hasattr(expr, "_jc"):
            jmap.put(col, expr._jc)           # Column._jc is the Java Column
        elif type(expr) is str:
            jmap.put(col, functions.expr(expr)._jc)  # SQL string → Column → Java
        ...
    return jmap
```

```python
# python/delta/tables.py:902-916
@staticmethod
def _condition_to_jcolumn(condition, argname="'condition'"):
    """Convert Python Column or SQL string to Java Column"""
    if isinstance(condition, Column) and hasattr(condition, "_jc"):
        return condition._jc
    elif type(condition) is str:
        return functions.expr(condition)._jc
    ...
```

The `_wrapped` attribute access pattern (`getattr(self._spark, "_wrapped", self._spark)`) avoids Spark 3.3.0+ deprecation warnings when wrapping returned JVM DataFrames:

```python
# python/delta/tables.py:59-64
return DataFrame(
    self._jdt.toDF(),
    getattr(self._spark, "_wrapped", self._spark)
)
```

### DeltaMergeBuilder (classic)

Wraps a JVM `DeltaMergeBuilder` object. Condition + set dictionaries are converted to Java before each call.

| Method | Description |
|--------|-------------|
| `whenMatchedUpdate(condition, set)` | Update matched row with `set` mapping |
| `whenMatchedUpdateAll(condition)` | Update all matched columns from source |
| `whenMatchedDelete(condition)` | Delete matched row |
| `whenNotMatchedInsert(condition, values)` | Insert from source for unmatched rows |
| `whenNotMatchedInsertAll(condition)` | Insert all columns from source |
| `whenNotMatchedBySourceUpdate(condition, set)` | Update target row with no source match |
| `whenNotMatchedBySourceDelete(condition)` | Delete target row with no source match |
| `withSchemaEvolution()` | Enable automatic schema evolution for merge |
| `execute()` | Execute merge; returns metrics `DataFrame` |

Three private builder factories delegate to JVM:

```python
# python/delta/tables.py:1249-1272
def __getMatchedBuilder(self, condition=None):
    if condition is None: return self._jbuilder.whenMatched()
    else: return self._jbuilder.whenMatched(DeltaTable._condition_to_jcolumn(condition))
```

### DeltaTableBuilder (classic)

Accumulates DDL parameters on the JVM-side builder object. Each method mutates `self._jbuilder` by calling the corresponding JVM method.

The `addColumn` method handles three column types:
1. **Generated expression**: `generatedAlwaysAs: str` → calls JVM `.generatedAlwaysAs(expr)`
2. **Identity column** (always): `generatedAlwaysAs: IdentityGenerator` → calls JVM `.generatedAlwaysAsIdentity(start, step)`
3. **Identity column** (by default): `generatedByDefaultAs: IdentityGenerator` → calls JVM `.generatedByDefaultAsIdentity(start, step)`

The `partitionedBy` and `clusterBy` methods use PySpark's `_to_seq` helper (with a Spark 4 import fallback from `pyspark.sql.classic.column`) to convert Python column lists to Scala sequences.

### DeltaOptimizeBuilder (classic)

| Method | Description |
|--------|-------------|
| `where(partitionFilter)` | Set partition filter string |
| `executeCompaction()` | Compact small files; returns metrics `DataFrame` |
| `executeZOrderBy(*cols)` | Z-Order by columns; returns metrics `DataFrame` |

### IdentityGenerator (dataclass)

```python
# python/delta/tables.py:1275-1285
@dataclass
class IdentityGenerator:
    start: int = 1
    step: int = 1
```

Passed to `addColumn` to configure IDENTITY column generation. Validated: `step` must be non-zero.

## Spark Connect API (`delta/connect/tables.py`)

The Connect-mode `DeltaTable` builds `DeltaLogicalPlan` objects (from `plan.py`) and submits them via `self._spark.client.execute_command()` (for commands) or wraps them in `DataFrame(plan, session=self._spark)` (for relations).

### Key Structural Difference vs. Classic

The Connect `DeltaTable` does not hold a JVM reference. Instead it stores:
- `self._path`: `Optional[str]` — filesystem path
- `self._tableOrViewName`: `Optional[str]` — catalog name
- `self._hadoopConf`: `Dict[str, str]`
- `self._plan`: `LogicalPlan` — current plan (starts as `DeltaScan`, aliased via `SubqueryAlias`)

The `_to_proto()` method serializes the table identity into a `proto.DeltaTable` message:

```python
# python/delta/connect/tables.py:411-417
def _to_proto(self) -> proto.DeltaTable:
    result = proto.DeltaTable()
    if self._path is not None:
        result.path.path = self._path
    if self._tableOrViewName is not None:
        result.table_or_view_name = self._tableOrViewName
    return result
```

### Command vs. Relation Dispatch

Operations fall into two categories:

**Commands** (fire-and-forget, no result DataFrame needed from server):
- `generate`, `vacuum`, `upgradeTableProtocol`, `addFeatureSupport`, `dropFeatureSupport`, `clone`, `cloneAtVersion`, `cloneAtTimestamp`
- Use: `plan_obj.command(session=self._spark.client)` → `self._spark.client.execute_command(command)`

**Relations** (return a DataFrame via DML-as-relation or query):
- `delete`, `update`, `merge.execute()`, `history`, `detail`, `isDeltaTable`, `restoreToVersion`, `restoreToTimestamp`, `optimize.executeCompaction()`, `optimize.executeZOrderBy()`
- Use: `DataFrame(plan, session=self._spark)` — result collected with `.toPandas()` then re-wrapped via `self._spark.createDataFrame(df.toPandas())`

> [!NOTE] Vacuum returns `None`
> `vacuum()` in Connect mode sends the command and returns `None` instead of an empty DataFrame (unlike classic mode). This is a known TODO (comment in `connect/tables.py:178`).

## Plan Serialization (`delta/connect/plan.py`)

`plan.py` defines the bridge between Python `DeltaTable` method calls and the Delta Connect proto schema.

### Class Hierarchy

```
DeltaLogicalPlan (extends pyspark.sql.connect.plan.LogicalPlan)
├── to_delta_relation() → proto.DeltaRelation  ← for Relations
└── to_delta_command()  → proto.DeltaCommand   ← for Commands

Relations (implement to_delta_relation):
  DeltaScan, DeleteFromTable, UpdateTable, MergeIntoTable,
  DescribeHistory, DescribeDetail, ConvertToDelta, IsDeltaTable,
  RestoreTable, OptimizeTable

Commands (implement to_delta_command):
  Generate, Vacuum, CreateDeltaTable, UpgradeTableProtocol,
  AddFeatureSupport, DropFeatureSupport, CloneTable
```

### Key plan.py classes

**`DeltaLogicalPlan`** (base):
```python
# python/delta/connect/plan.py:33-47
def plan(self, session: SparkConnectClient) -> spark_proto.Relation:
    plan = self._create_proto_relation()
    plan.extension.Pack(self.to_delta_relation(session))  # Pack into Any
    return plan

def command(self, session: SparkConnectClient) -> spark_proto.Command:
    command = spark_proto.Command()
    command.extension.Pack(self.to_delta_command(session))  # Pack into Any
    return command
```

The `Pack()` call serializes the Delta-specific proto into the Spark Connect `Any` extension field. On the server side, `DeltaRelationPlugin` / `DeltaCommandPlugin` unpack and dispatch.

**`Assignment`**: Pairs a field `Column` with a value `Column`, serialized to `proto.Assignment`:
```python
# python/delta/connect/plan.py:92-101
def to_proto(self, session) -> proto.Assignment:
    assignment = proto.Assignment()
    assignment.field.CopyFrom(self._field.to_plan(session))
    assignment.value.CopyFrom(self._value.to_plan(session))
    return assignment
```

**`MergeAction`** hierarchy (5 classes):
- `UpdateAction`: condition + list of `Assignment`
- `UpdateStarAction`: condition only; sets `update_star_action` marker
- `DeleteAction`: condition only; sets `delete_action` marker
- `InsertAction`: condition + list of `Assignment`
- `InsertStarAction`: condition only; sets `insert_star_action` marker

**`MergeIntoTable`**: aggregates target, source, condition, and three action lists:
```python
# python/delta/connect/plan.py:222-237
def to_delta_relation(self, session) -> proto.DeltaRelation:
    relation = proto.DeltaRelation()
    relation.merge_into_table.target.CopyFrom(self._target.plan(session))
    relation.merge_into_table.source.CopyFrom(self._source.plan(session))
    relation.merge_into_table.condition.CopyFrom(self._condition.to_plan(session))
    # ... matched/not_matched/not_matched_by_source actions extend()
    relation.merge_into_table.with_schema_evolution = self._with_schema_evolution
    return relation
```

### Proto Directory (`delta/connect/proto/`)

Three generated Python protobuf modules (auto-generated by `sbt protoc`, listed as generated/vendored in the manifest):
- `base_pb2.py` — `DeltaTable` message: `{path: TablePath | table_or_view_name: str, hadoop_conf: map<str,str>}`
- `commands_pb2.py` — `DeltaCommand` oneof (7 types: VacuumTable, UpgradeTableProtocol, Generate, CreateDeltaTable, AddFeatureSupport, DropFeatureSupport, CloneTable)
- `relations_pb2.py` — `DeltaRelation` oneof (10 types: Scan, DescribeHistory, DescribeDetail, ConvertToDelta, RestoreTable, IsDeltaTable, DeleteFromTable, UpdateTable, MergeIntoTable, OptimizeTable)

## Exception Classes (`delta/exceptions/`)

All exception classes are plain subclasses of PySpark's `PySparkException`. No additional logic — they serve as typed exception handles for catching specific conflict scenarios in user code.

| Class | Description |
|-------|-------------|
| `DeltaConcurrentModificationException` | Base class for all conflict exceptions |
| `ConcurrentWriteException` | Concurrent transaction wrote after current read |
| `MetadataChangedException` | Metadata changed between read and commit |
| `ProtocolChangedException` | Protocol version changed between read and commit |
| `ConcurrentAppendException` | Files added that current tx would have read |
| `ConcurrentDeleteReadException` | Current tx reads data deleted concurrently |
| `ConcurrentDeleteDeleteException` | Current tx deletes data deleted concurrently |
| `ConcurrentTransactionException` | Two txns try to update same idempotent tx |

`exceptions/captured.py` contains Py4J exception capture and re-raise utilities (not documented in detail as it is thin glue code).

## Installation & Configuration

### pip install

```bash
pip install delta-spark
```

This installs the Python bindings only. The JVM Delta JAR must be added separately.

### `configure_spark_with_delta_pip()` (`delta/pip_utils.py`)

Utility that reads the installed `delta_spark` package version via `importlib_metadata` and constructs the correct Maven artifact coordinate:

```python
# python/delta/pip_utils.py:86-93
if spark_version:
    spark_major_minor = ".".join(spark_version.split(".")[:2])  # e.g. "4.0" or "4.1"
    artifact_name = f"delta-spark_{spark_major_minor}_{scala_version}"
else:
    artifact_name = f"delta-spark_{scala_version}"  # fallback for unknown Spark version

maven_artifact = f"io.delta:{artifact_name}:{delta_version}"
```

The resulting artifact string (e.g. `io.delta:delta-spark_4.1_2.13:4.1.0`) is passed to `spark.jars.packages`. Spark downloads the JAR from Maven Central at session startup.

Additional packages can be injected via `extra_packages`.

### Version

`delta/version.py` is auto-generated by `build/sbt sparkV1/generatePythonVersion`. Current: `4.1.0`.

## Usage Examples

### Classic PySpark — Read/Write/Merge

```python
from delta.tables import DeltaTable
from delta import configure_spark_with_delta_pip
from pyspark.sql import SparkSession

spark = configure_spark_with_delta_pip(
    SparkSession.builder
        .master("local[*]")
        .config("spark.sql.extensions", "io.delta.sql.DeltaSparkSessionExtension")
        .config("spark.sql.catalog.spark_catalog",
                "org.apache.spark.sql.delta.catalog.DeltaCatalog")
).getOrCreate()

# Write
df.write.format("delta").save("/path/to/table")

# Read
spark.read.format("delta").load("/path/to/table").show()

# DeltaTable operations
dt = DeltaTable.forPath(spark, "/path/to/table")
dt.history(5).show()
dt.vacuum(168)

# Merge
dt.alias("tgt").merge(
    updates.alias("src"),
    "tgt.id = src.id"
).whenMatchedUpdateAll() \
 .whenNotMatchedInsertAll() \
 .execute()
```

### Spark Connect Mode

```python
from pyspark.sql.connect.session import SparkSession
from delta.tables import DeltaTable  # same import — auto-dispatches

spark = SparkSession.builder.remote("sc://localhost").getOrCreate()

# Works exactly like classic mode — DeltaTable.forPath detects is_remote()
dt = DeltaTable.forPath(spark, "/path/to/table")
dt.delete("id < 0")
```

### Create Table with DeltaTableBuilder

```python
DeltaTable.create(spark) \
    .tableName("events") \
    .addColumn("id", "LONG", nullable=False,
               generatedAlwaysAs=IdentityGenerator(start=1, step=1)) \
    .addColumn("ts", "TIMESTAMP") \
    .addColumn("payload", "STRING") \
    .partitionedBy("date") \
    .property("delta.enableChangeDataFeed", "true") \
    .execute()
```

## Key Differences: Classic vs. Connect Mode

| Aspect | Classic PySpark | Spark Connect |
|--------|----------------|---------------|
| Session type | `pyspark.sql.SparkSession` (local JVM) | `pyspark.sql.connect.session.SparkSession` (remote) |
| JVM bridge | Py4J `_jvm` / `_jdt` | None — proto serialization |
| Column type | `pyspark.sql.Column` with `_jc` attribute | `pyspark.sql.connect.column.Column` |
| DataFrame type | Classic `DataFrame` with `_jdf` | Connect `DataFrame` backed by `LogicalPlan` |
| Condition serialization | `_condition_to_jcolumn()` → Java Column | `_condition_to_column()` → Connect Column |
| Set serialization | `_dict_to_jmap()` → Java HashMap | `_dict_to_assignments()` → `List[Assignment]` |
| DML result | Direct JVM result DataFrame | `.toPandas()` → `createDataFrame()` round-trip |
| `vacuum()` result | Empty DataFrame | `None` (known gap) |
| `alias()` impl | Calls `self._jdt.alias()` | Wraps in `SubqueryAlias(self._plan, aliasName)` |
| Schema in `addColumn` | Parsed via `jsparkSession.parseDataType(schema.json())` | `pyspark_types_to_proto_types(dataType)` |
| Builder state | Mutable JVM builder (chaining mutates JVM object) | Immutable Python lists/dicts accumulated, sent in single `execute()` |
